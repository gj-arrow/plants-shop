# Sitemap для plant-shop — дизайн

Дата: 2026-08-18
Статус: утверждено пользователем

## Цель

Добавить `/sitemap.xml` для сайта, чтобы его страницы были видны поисковикам (Google, Яндекс). Пользователь планирует добавить адрес sitemap в Google Search Console и Яндекс.Вебмастер.

## Решения

1. **Динамический sitemap через Next.js** — файл `src/app/sitemap.ts` по конвенции Next.js, отдаёт `/sitemap.xml`. URL генерируются из БД при каждом запросе — добавленные в админке товары попадают в sitemap автоматически, без перегенерации.
2. **Домен захардкожен**: `https://xn----ctbhcrqcg4cxb8cg8a.xn--90ais` — punycode-форма `цветы-людмилы.бел`. Дополнительных переменных окружения не требуется.
3. **Включаются все товары**, включая `out_of_stock = 1` (решение пользователя).

## URL в sitemap

- `/` — главная (каталог)
- `/products/{id}` — страница каждого товара (для всех товаров из таблицы `products`)

Исключаются: `/admin/*`, `/api/*`, `/login`, `/favorites` — служебные страницы.

## Реализация

- Файл: `src/app/sitemap.ts`
- Запрос к БД: `queryAll('SELECT id, name, created_at FROM products')` через `src/lib/db.ts`
- `export const dynamic = 'force-dynamic'` — чтобы sitemap не генерировался статически при локальной сборке (сборка идёт локально, БД хостинга доступна только в рантайме на ISPmanager).
- `lastModified` — из `created_at` товара (если есть), для главной не указываем.
- `changeFrequency` / `priority` — не указываем (Google их игнорирует, Яндекс принимает опционально).

## Проверка

- `npm run dev` → открыть `http://localhost:3000/sitemap.xml` — виден XML со списком товаров из локальной БД.
- `npm run build` — сборка проходит без ошибок (sitemap не генерируется на этапе сборки из-за `force-dynamic`).
- После деплоя: `https://xn----ctbhcrqcg4cxb8cg8a.xn--90ais/sitemap.xml` отдаёт XML.

## Вне рамок

- Само добавление sitemap в Search Console / Вебмастер — делается вручную в интерфейсе поисковиков.
- Гарантия индексации — sitemap лишь помогает, страницы индексируются поисковиком самостоятельно.
